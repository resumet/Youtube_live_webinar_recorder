# Windows 수동 확인

자동화 범위와 남은 항목은 [수용 기준 점검표](ACCEPTANCE.md)를 따른다.
아래 검사는 Windows 10/11 각각에서 수행한 운영체제 버전과 결과를 기록한다.
프로그램이 구현되어 있다는 사실과 실제 셸에서 관찰한 결과를 구분한다.

## 실제 콘텐츠를 받지 않는 트레이·알림 검사

개발 환경을 준비한 PC에서 프로젝트 폴더를 열고 다음 명령을 실행한다.

```powershell
.\.venv\Scripts\python.exe scripts/manual_shell_check.py
```

이 명령은 새 UUID 폴더에 짧은 영상을 자체 생성해 FFprobe로 검사한 뒤 프로그램 화면을 연다.
방송 시작/완료 상태는 모의 응답이고, 제품의 트레이·알림 처리 코드를 그대로 사용한다.
외부 YouTube 접속과 실제 방송 등록은 하지 않는다. 기존 사용자 DB·영상도 변경하지 않는다.
검사 화면의 등록/설정은 비활성화되어 있으며 최대 10분 뒤 자동 종료한다.

1. **트레이·알림 로컬 검증** 창을 찾는다. 창이 열리고 약 1초 뒤 시작 알림이 표시되는지 확인한다.
2. 창의 X를 누른다. 앱이 종료되지 않고 트레이에 남아야 한다. 숨겨진 아이콘 목록도 확인한다.
3. **YouTube Live Recorder** 트레이 아이콘을 클릭해 같은 창이 복원되는지 확인한다.
4. 복원한 창 위쪽의 **완료 알림 표시**를 누른 뒤 **녹화 저장 완료** 알림을 클릭한다.
   알림을 놓쳤으면 같은 버튼으로 다시 표시할 수 있다.
5. 탐색기에 검증 영상이 있는 폴더가 열리는지 육안으로 확인한다.
6. 창 위쪽 **결과 저장 후 종료**를 누른다. 콘솔에 출력된 `result.json` 경로를 확인한다.

검사 결과에는 창 숨김, 트레이 활성화 후 복원, 알림 클릭 횟수와 대상, 폴더 열기 요청,
정상 종료 여부를 기록한다. 이벤트마다 JSON을 저장하며 `검사 진행 중` 필드로 최종 결과와 구분한다.
탐색기가 실제 표시되었는지는 사용자 확인으로 보완해야 한다. 알림 배너가 보이지 않으면
Windows의 알림 센터와 방해 금지 상태를 확인하되, 검증 도구는 시스템 설정을 변경하지 않는다.
이 결과는 실제 YouTube 녹화, 설치된 실행 파일, Windows 전체 버전의 검증을 대신하지 않는다.

`--smoke` 옵션은 offscreen으로 화면 흐름과 종료만 확인한다. 실제 클릭 검증으로 간주하지 않는다.

## 설치본에서 확인할 항목

설치된 프로그램에서도 창 닫기/최소화/트레이 복원, 허가받은 방송의 시작·완료 알림과 폴더 열기를 확인한다.
설치·재설치·제거의 자동 검사 절차는 [패키징 안내](PACKAGING.md)에 있다.

결과를 공유할 때에는 Windows 버전, 설치 파일 SHA256, 확인 시각과 항목별 성공/실패를 남긴다.
일부 공개 방송 URL이나 영상 자체를 공개 저장소에 올리지 않는다.
