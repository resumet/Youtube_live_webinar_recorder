# PRD 수용 기준과 검증 범위

기준일: 2026-10-19. 구현과 실제 서비스·운영체제 검증은 구분한다.
전체 자동화 테스트는 160개 통과했다. 상세 수치와 단계별 이력은 [검증 기록](VALIDATION.md)에 있다.
아래의 자동화 근거는 별도 표시가 없으면 모의 방송 응답 또는 로컬 생성 영상을 사용한다.

파일명만 표시한 테스트는 `tests/unit/` 또는 `tests/integration/`에 있다.

Windows 11에서 개발·검증했다. 네이티브 Qt의 100/125/150/200% 배율 시뮬레이션과 작은 화면의
버튼 접근을 확인했다. Windows 10, 물리적 다중 모니터 간 이동 및 다른 PC 설치는 미검증이다.

## 설치 후보와 남은 배포 작업

- 최신 후보 번들: `dist/candidate/YouTubeLiveRecorder/`. 화면 배율 보완 커밋 `5c2a3a9`를 반영했다.
- 설치 파일: `dist/installer/YouTubeLiveRecorder-0.1.0-Setup.exe`.
- 현재 파일의 SHA256은 같은 폴더의 `.exe.sha256` 파일과 대조한다. 후보별 해시는 검증 기록에 남긴다.
- 진행 중인 3시간 시험은 `beaacf3` 번들을 유지한다. 이후의 변경은 파일명 날짜 추정 안내와
  설치 후보 경로 선택과 화면 크기/스크롤 보완이다. UI 보완 전 후보는 별도 Windows 실행/미디어/
  짧은 연속 시험을 통과했다. UI 보완 후 후보도 Windows 실행/미디어 및 네 배율 화면 검사를 통과했다.
- GitHub의 연결 계정 쓰기 권한이 확인되면 보존된 단계별 커밋을 업로드한다. 현재는 로컬 커밋 상태다.
- 실제 업데이트 주소는 PRD에 따라 비어 있다. 코드 서명과 공개 바이너리 배포용 라이선스 자료는
  [외부 구성요소 고지](THIRD_PARTY.md)의 준비 상태를 따른다.

## 로컬 시험 결과 확인

개발 폴더 `.runtime/`는 Git에서 제외한다. 허가 방송의 URL·제목·녹화 파일은 공개 저장소에 넣지 않는다.

- `.runtime/soak-3h-20261019/result.json`: 연속 시험 진행률과 최종 정상 종료 결과.
- `.runtime/final-validation/result.json`: 3시간 성공 및 프로세스 종료 확인 후 설치 검사 실행 상태.
- `.runtime/installer-tests/<시험 ID>/`: 설치·재설치·제거 로그와 사용자 데이터 보존 결과.
- `.runtime/bundle-replay-test/<시험 ID>/`: 허가받은 추가 방송의 번들 다시보기 검사 결과.

진행 중 JSON의 `성공: false`는 최종 실패 판정이 아니다. 정상 종료 필드와 최종 단계 및 오류를
함께 확인한다. 짧은 시험 결과를 3시간 시험 결과로 대신하지 않는다.
